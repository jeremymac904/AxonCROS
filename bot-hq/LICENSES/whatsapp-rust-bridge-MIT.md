## Provenance of this notice

This notice covers the npm package `whatsapp-rust-bridge` (pinned version
`0.5.4` in `bot-hq/package-lock.json`).

The published npm tarball for that package **does not contain a LICENSE
file**, and neither the declared upstream repository nor its fork contains
one. GitHub's own licence detection reports no licence for either
repository. This notice is therefore reconstructed from the npm registry
metadata for the package, which declares `"license": "MIT"`, names the author
as João Lucas, and points at the declared upstream repository, together with
the MIT licence text published by the Rust project the bridge compiles
(`whatsapp-rust`, MIT, "Copyright (c) 2025 João Lucas de Oliveira Lopes").

It is reproduced here so that redistributed copies carry the notice the MIT
licence requires. Anyone redistributing this software should confirm the
notice against the package author's current published terms.
